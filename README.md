# ApneDoctors

A complete care app for India: find a doctor, book, consult, get medicines and tests at home, and keep the
whole family's health in one place.

- `apps/patient/`: the patient app (Flutter, iOS + Android). Start with [apps/patient/CLAUDE.md](apps/patient/CLAUDE.md).
- `docs/design/kalighat-pop/`: design boards ("Kalighat pop").
- `docs/product/`: decisions, edge cases, screens.
